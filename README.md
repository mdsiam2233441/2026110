# 🤖 Claude AI Telegram Bot

একটি ফাইলের (`bot.py`) ভেতরে সম্পূর্ণ টেলিগ্রাম বট, যা Claude (Anthropic API) দিয়ে চলে। এতে আছে অ্যাকাউন্ট সিস্টেম, প্রিমিয়াম, নিজের API Key সেটআপ আর রঙিন বাটন মেনু।

> **মনে রাখবেন:** `claude.ai/chat` ওয়েবসাইট বট থেকে সরাসরি ব্যবহার করা যায় না। বটটি Anthropic API ব্যবহার করে, যার জন্য আলাদা API key ও ব্যবহার অনুযায়ী বিলিং লাগে।

## 📦 প্রয়োজনীয় জিনিস

- Python 3.9 বা তার উপরের ভার্সন
- টেলিগ্রাম বট টোকেন ([@BotFather](https://t.me/BotFather) থেকে)
- Anthropic API key ([console.anthropic.com](https://console.anthropic.com) থেকে)
- আপনার টেলিগ্রাম আইডি ([@userinfobot](https://t.me/userinfobot) থেকে)

## 🚀 ইনস্টল ও চালানোর ধাপ

### ধাপ ১: বট তৈরি
1. টেলিগ্রামে `@BotFather` খুলুন
2. `/newbot` দিন, নাম ও ইউজারনেম দিন
3. যে টোকেন পাবেন সেটি কপি করুন

### ধাপ ২: API key নিন
1. [console.anthropic.com](https://console.anthropic.com) এ লগইন করুন
2. **API Keys** থেকে নতুন key তৈরি করুন (`sk-ant-…` দিয়ে শুরু হয়)
3. বিলিংয়ে ক্রেডিট যোগ করুন

### ধাপ ৩: লাইব্রেরি ইনস্টল
```bash
pip install "python-telegram-bot>=20" anthropic
```

### ধাপ ৪: কনফিগারেশন
`bot.py` এর উপরের **ধাপ ১: কনফিগারেশন** অংশে নিজের তথ্য বসান:

```python
BOT_TOKEN = "আপনার_বট_টোকেন"
OWNER_API_KEY = "sk-ant-..."
ADMIN_IDS = {123456789}          # আপনার টেলিগ্রাম আইডি
PREMIUM_CONTACT = "@your_username"
```

অথবা ফাইল না বদলে Environment Variable ব্যবহার করুন:

```bash
export BOT_TOKEN="..."
export ANTHROPIC_API_KEY="sk-ant-..."
export ADMIN_IDS="123456789"
export PREMIUM_CONTACT="@your_username"
```

### ধাপ ৫: চালান
```bash
python bot.py
```
টার্মিনালে `🚀 বট চালু হয়েছে!` দেখলে সফল।

### ধাপ ৬: টেস্ট
1. বটে `/start` দিন
2. একটা প্রশ্ন লিখুন
3. `/admin` দিয়ে অ্যাডমিন কমান্ডগুলো দেখুন

## ⚙️ কনফিগারেশন তালিকা

| ভেরিয়েবল | কাজ | ডিফল্ট |
|---|---|---|
| `BOT_TOKEN` | টেলিগ্রাম বট টোকেন | — |
| `ANTHROPIC_API_KEY` | বটের মালিকের API key | — |
| `ADMIN_IDS` | অ্যাডমিনদের আইডি (কমা দিয়ে আলাদা) | — |
| `CLAUDE_MODEL` | ব্যবহৃত Claude মডেল | `claude-sonnet-5-5` |
| `FREE_DAILY_LIMIT` | ফ্রি ইউজারের দৈনিক মেসেজ সীমা | `10` |
| `PREMIUM_CONTACT` | প্রিমিয়াম কিনতে যোগাযোগ | — |

## 💬 ইউজার কমান্ড

| কমান্ড | কাজ |
|---|---|
| `/start`, `/menu` | মূল মেনু |
| `/new` | নতুন চ্যাট শুরু (ইতিহাস মোছা) |
| `/account` | অ্যাকাউন্ট দেখা |
| `/redeem CODE` | প্রিমিয়াম কোড ব্যবহার |
| `/help` | সাহায্য |

## 👑 অ্যাডমিন কমান্ড

| কমান্ড | কাজ |
|---|---|
| `/admin` | অ্যাডমিন প্যানেল |
| `/grant user_id দিন` | প্রিমিয়াম দেওয়া (যেমন `/grant 123456 30`) |
| `/revoke user_id` | প্রিমিয়াম বাতিল |
| `/gencode দিন [সংখ্যা]` | প্রিমিয়াম কোড তৈরি (যেমন `/gencode 30 5`) |
| `/ban user_id` / `/unban user_id` | ব্লক / আনব্লক |
| `/stats` | ইউজার ও প্রিমিয়ামের পরিসংখ্যান |
| `/broadcast মেসেজ` | সব ইউজারকে মেসেজ পাঠানো |

## 🔒 নিরাপত্তা

- ইউজার API key পাঠালে বট মেসেজটি সাথে সাথে মুছে দেয়।
- key গুলো `bot.db` ফাইলে সাধারণ টেক্সটে জমা থাকে। ফাইলটি সুরক্ষিত রাখুন এবং কাউকে শেয়ার করবেন না।
- `bot.py` বা `bot.db` GitHub-এ আপলোড করবেন না। আপলোড করলে আগে টোকেন ও key সরিয়ে নিন।
- বেশি ইউজার থাকলে Anthropic ড্যাশবোর্ডে খরচ নিয়মিত দেখুন।

## ☁️ সবসময় চালু রাখা

কম্পিউটার বন্ধ হলে বটও বন্ধ হয়ে যায়। সবসময় চালু রাখতে VPS বা Railway/Render-এর মতো হোস্টিং ব্যবহার করুন। Linux সার্ভারে `screen` বা `systemd` দিয়ে চালানো যায়:

```bash
screen -S bot
python bot.py
# Ctrl+A তারপর D চাপলে ব্যাকগ্রাউন্ডে চলবে
```

## 🛠 সমস্যা হলে

| সমস্যা | সমাধান |
|---|---|
| `BOT_TOKEN বসান` এরর | কনফিগে সঠিক টোকেন বসান |
| বট উত্তর দেয় না | `ANTHROPIC_API_KEY` ঠিক আছে কি না এবং বিলিংয়ে ক্রেডিট আছে কি না দেখুন |
| `API Key সঠিক নয়` | key আবার কপি করুন, শুরুতে `sk-ant-` আছে কি না দেখুন |
| `/admin` কাজ করে না | `ADMIN_IDS` এ আপনার সঠিক আইডি আছে কি না দেখুন |
| `/grant` এ ইউজার পাওয়া যায় না | ইউজারকে আগে বটে `/start` দিতে হবে |
| মডেলের এরর | `CLAUDE_MODEL` বদলে Anthropic ডকুমেন্টেশনে দেওয়া সচল মডেলের নাম দিন |
